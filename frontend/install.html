Get it on your phone

llm-style is a web app that installs like a native one — no App Store, no download queue. Your phone and this computer just need to be on the same Wi-Fi.

  1. Scan the QR code below with your phone's camera.
  2. The app opens in your mobile browser.
  3. Tap Share → Add to Home Screen (iPhone) or the browser menu → Install app (Android).
  4. It now sits on your home screen and works like any app — including your wardrobe photos.

Once installed, the app remembers your machine's address. Keep the backend running (uvicorn app.main:app --host 0.0.0.0) so the phone can reach it.

On this computer

You can install it here too: in Safari use File → Add to Dock; in Chrome/Edge, the install icon in the address bar.
